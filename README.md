# rlvr-project
Training a Qwen2.5-0.5B base model to code using Reinforcement Learning with Verifiable Rewards (RLVR) &amp; GRPO. Features an automated Python jail grader, zero human-in-the-loop traceback self-correction, and Unsloth VRAM optimizations to run massive GRPO rollouts on consumer Kaggle Dual T4 GPUs.
